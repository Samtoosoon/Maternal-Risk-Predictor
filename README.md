An **AI-powered web application** that predicts **maternal pregnancy risk** (**Low / Medium / High**) using basic clinical and demographic inputs.  
Built to support **ASHA and frontline health workers** in early identification of high-risk pregnancies, enabling timely interventions—especially in **rural and low-resource settings**.

---

## 🔑 Highlights

- ✅ **92% accuracy** using **XGBoost + Ensemble models**
- 🔍 **Explainable predictions** with key contributing factors
- 🩺 **WHO-aligned clinical insights**
- 🌐 **ReactJS frontend + Flask backend**
- 🧪 **Preloaded demo profiles** for instant testing

---

## 🧠 Input Features

The model uses commonly available maternal health indicators:

- Age  
- Systolic & Diastolic Blood Pressure  
- Blood Sugar Levels  
- Hemoglobin (Hb)  
- Body Mass Index (BMI)  
- Heart Rate  
- Previous Pregnancies  
- Antenatal Care (ANC) Visits  
- Location (Urban / Rural)

---

## 📈 Model Output

- **Risk Category:** Low / Medium / High  
- **Confidence Score**
- **Top contributing health risk factors**
